# 导航与界面

四个根级入口依次为连接、服务器、高级、设置，各自保留导航栈。紧凑窗口使用底部导航，
宽窗口使用侧边导航；功能与数据合同不随尺寸变化。详情使用页面间导航，共享底部操作栏
固定显示；弹窗保留自己的操作区。

Material 控件和主题统一使用 `material_ui`，与 `go_router` 的页面类型识别保持一致；
普通页面保留平台默认转场和 iOS 侧滑返回，不自行模拟返回手势。
系统控件本地化使用 `AppLocalePolicy.localizationsDelegates`，不使用生成文件中旧版 SDK 的
代理列表。尚未迁移的第三方 JSON 编辑器、Markdown 和扫码控件仅在各自边界使用官方
`MaterialUiCompatibilityBridge`；第三方依赖迁移后移除对应桥接。

按钮反馈按实际操作区分：异步操作保留按钮内 loading；保存成功使用共享 toast，失败或取消
不显示成功提示。恢复默认只修改编辑草稿，提示仍需保存，不隐式写入数据库或重连。
导航、选项切换、草稿内增删等已有直接视觉反馈的操作不重复提示；系统跳转失败时显示 toast。

Outgoing sharing uses the shared `ShareAction` around the existing buttons.
Only the active share button shows loading and rejects duplicate activation;
other page actions remain independent. A native share result never closes the
share page or claims delivery. Linux shows an explicit copy label and icon with
the existing two-second copy toast. Raw/custom sharing keeps its sensitive-data
confirmation. Page departure suppresses late dialogs and feedback; losing window
focus alone is not cancellation. See [sharing](subscriptions-and-sharing.md#outgoing-system-sharing).

## 公共主题与布局

原型公共配置按语义映射到 [主题目录](../lib/pages/theme/)，App 不在运行时读取原型 JSON。
`color.dart` 负责明暗色板，区分链接/图标色与实心按钮色；`font.dart` 按文字角色定义字号与
字重，字号为不小于 12 的整数，字重使用整百值，不配置行高、字距或 `fontVariations`；
`layout.dart` 负责公共尺寸、间距、圆角和导航断点。
`theme.dart` 把同一套角色应用到 Material 与 Shad 控件，不在页面重复定义样式。

根路由按窗口宽度选择标题、按钮等公共主题尺寸；紧凑桌面仍显示带文字的侧栏。
`ResponsiveContent` 只限制可用内容区宽度，不叠加页面自己的内边距。
`PageActionBar` 使用最小尺寸，允许动作换行，并保留安全区和键盘避让；Shad 按钮高度
随系统字号放大。代码继续使用 App 已打包的 GeistMono；Windows 中文字形依次回退到
Microsoft YaHei UI、Microsoft YaHei，其它平台保留系统字体回退。不照搬浏览器的字体栈
或预览工具栏尺寸。

页面特有的尺寸覆盖和完整视觉验收仍需逐页核对；修改公共角色前应检查其他消费页。

## 连接

普通模式选择自动、位置、订阅或固定节点，再选择智能路由、全部使用 VPN 或自定义路由。
自动选择按当前路由需要选取 1–3 个可用接入节点；固定节点和全部使用 VPN 使用一个。
智能路由可以独立配置最终出口，接入节点排除该出口。
直连地区与初始化共用单选页面：选择新地区替换当前选择，重复点击已选项不取消；
保留搜索、清空和“完成”，返回或取消不保存选择。

专家模式以 Raw JSON 选择替换整个服务器区域；普通选择仍保留，二者不混用。
Raw 新增最多三份；已有超额旧数据仍完整显示、可编辑和选择，添加入口隐藏。
首页展示状态、实时速率及本次连接上下行，不展示累计流量。流量卡片仅展示数据，不提供点击入口或详情弹窗。
不提供把单个出口 IP 冒充多节点真实出口的“连接信息”。

涉及当前运行配置的变更通过协调器确认、重连与提交；先停止当前 VPN，再准备、校验并启动新配置。
停止失败不进入启动流程；已进入原生启停后失败则停在失败状态，不自动重启旧连接。编辑未启用资产或仅改名称不重连。

## 服务器

按订阅与按节点位置依次作为两个 Tab，默认选中按订阅，共享分组详情和节点行。分组与节点可直接使用，
当前运行中的节点高亮；节点行显示协议、传输与安全标签。
订阅分组按订阅 ID 升序排列，“手动添加”在有本地节点时置顶，无本地节点时隐藏；管理订阅使用相同顺序。
节点延迟标签与连接页共用判定：≤500 ms 为“快”，>500 且 ≤1000 ms 为“慢”，
超过 1000 ms 为“可用”；未测速、失败和超时继续使用原状态，不参与延迟分级。
连接首页的“服务器”切换到服务器根 Tab，支持自动选择、订阅、位置或单个节点；
选择后保留当前服务器页面，分组返回分类页，不自动返回连接首页。

节点、订阅均支持编辑、分享和删除。节点编辑使用 JSON；订阅编辑复用添加表单及 Age
操作。普通节点导入、添加订阅与刷新不预览、不二次确认，非空结果才提交；失败保留原数据与表单。
二维码扫描仅 iOS/Android 显示，文件导入直接进入系统选择器。

测速不锁定节点或订阅菜单；自动测速与手动的订阅、位置、单节点测速共用 FIFO 队列，
正在测速时后续请求（含重复请求）继续排队，不以“正在测速”为由拒绝。
订阅、位置详情页提交批量测速后，按钮切换为“取消”；取消只作用于该分组的手动请求，
完成并保存当前批次后停止后续批次，尚未执行的请求直接跳过，不影响其他分组、单节点或自动测速。

## 高级

高级是第三个根级入口，分为“VPN 隧道”和“Xray”两个 Tab。

- VPN 隧道：只读 TUN 地址、可编辑的 IPv4/IPv6 DNS 和服务器域名，以及独立 IPv6 开关。
  DNS 输入保留在本页；域名提示说明其仅用于 Apple DoT。平台配置使用详情页。
  出口网卡只在 Windows/Linux 显示，必须明确选择。
- Apple：始终开启、按需 Wi-Fi 连接/断开规则及平台对应的蜂窝/Ethernet；接管全部流量
  打开后显示四项系统排除设置。关闭时可编辑绕过 VPN 的 IPv4/IPv6 网段，默认列表为空；
  重新打开后隐藏编辑控件、提示列表不生效，并保留已保存的内容。修改有效网段时复用
  已连接状态下的“保存并重新连接”。网段排除不自动改变 DNS 服务器。功能按原生能力显示。
- Android：全部、仅所选、除所选以外三种模式；包含与排除列表独立保存，保留应用图标。
- Windows 系统 VPN：仅 MSIX 模式提供自动连接、局域网绕过和排除网段；EXE 隐藏该入口，
  不应用或校验这些停用策略，也不因其变化要求重连。两种模式均保留出口网卡与其他公共设置。
- Xray：路由数据独立页、订阅/Geodata 更新周期、测速 URL/超时、统一日志开关与策略、
  独立访问/错误日志页、最近实际生成的只读配置。
  `systemExtension = true` 时隐藏整个日志区域及其保存/恢复默认按钮，不提供原生日志读取；
  其他平台保留本地日志查看与导出，路由数据和运行配置入口不受影响。

高级页不提供 Proxy 调试开关。iOS 模拟器由 Swift 自动适配本地 SOCKS，
不参与页面状态或策略保存；真机继续使用系统 VPN。

## 设置

设置管理外观、语言、Apple 图标、启动行为、清理数据和关于页。
关于区展示 App 与 Xray-core 版本；有新版本时关于入口显示圆点，桌面侧栏显示更新提醒。
语言为简体中文、繁体中文、英语、俄语、波斯语及跟随系统，文本复用已批准的原型。
主题和语言默认跟随系统；已保存的用户选择优先，未支持的系统语言回退为英语。
Linux ARM64 保留 CJK 兼容回退：请求语言为中文、日文或韩文时实际使用英语，覆盖跟随系统、
手动选择及托盘/通知等无页面上下文的文案读取；不改写已保存的语言选择。其它平台及
Linux x64 不应用该回退，继续按支持的语言正常解析。
波斯语界面 RTL，JSON、URL、IP、端口与日志内容保持 LTR。
隐私政策使用 HTTPS 链接，App 不内置隐私正文，不收集匿名分析数据。

## 实现入口

### 系统快捷入口

移动端仅使用 `quick_actions` 的 App 图标快捷菜单，固定提供启动 VPN、停止 VPN、切换配置、
更新订阅四项，不接入 App Intents、Siri 或系统自动化。切换配置复用现有页面：普通模式进入
服务器根页，专家模式进入连接页的 Raw JSON 选择区；不额外实现一套配置选择器。

桌面端独立使用 `tray_manager`：启停与重新连接、自动/订阅/位置/单节点选择、Raw JSON 选择、
流量方式、订阅更新、路由数据更新，以及现有显示窗口和退出操作。配置列表由数据库 stream
更新；订阅按 ID、节点按延迟排列，旧有超额 Raw 配置仍完整列出。专家模式禁用普通流量方式，
选择服务器会显式返回普通模式并保留原路由选择。
macOS/Windows 的托盘菜单打开期间不替换菜单，避免后台更新使当前菜单的点击失效；
关闭后合并发布最新数据，菜单操作不受全局禁用限制。

两个平台只共享连接协调器、配置提交、订阅和 Geodata 更新等业务实现，不共用菜单结构。
已连接时切换配置复用页面的确认并重连流程；未连接时只保存选择，不自动启动 VPN。
订阅可更新全部或单个来源，汇报有效导入数量和具体失败，不等待后续测速。
路由数据可更新全部、默认数据对或单个自定义文件；默认 geosite/geoip 始终一起更新，
失败保留旧文件，不触发 VPN 重连。托盘使用系统通知反馈结果，不因普通更新失败抢占窗口。
更新中的菜单项显示等待状态，其他无关操作保持可用。

### 错误反馈

错误保留操作与原始原因，区分输入、配置、网络、权限、本地读写、状态冲突和运行失败；
未知错误不猜测为网络问题。提示标题复用现有国际化文案，系统与 libXray 的诊断保留来源文本，
不重新翻译或改写内核错误。配置仍由 libXray 校验，不因提示分类增加 App 侧校验。

- 连接页、托盘和快捷方式共用连接失败解释，区分节点不足、权限、网卡、校验、启停失败与超时。
  原生桥保留系统返回的具体错误；Android 异步启动失败通过状态广播传递原因，Apple 在系统支持时
  读取本次启动失败的断开原因。错误信息不替代原生 VPN 状态。
- 表单保留输入与错误，JSON 编辑器可复制内核诊断，长错误可滚动查看，不遮挡保存按钮。
  页面加载失败展示可用的具体原因并保留重试；设置页保留操作失败详情。
- 订阅区分下载、Age 解密、空内容和保存失败，更新失败保留原节点；HTTP 错误保留状态码，
  不把整个请求对象或响应体当作提示。取消、被新操作替代的更新不显示失败。
- Geodata 下载、文件读写和删除失败不再统一提示检查网络，自动更新失败不影响 VPN 状态。
  测速失败保留在当前进程的节点行中，位置识别失败与延迟请求失败分开展示，成功重试清除旧提示；
  不写入数据库或建立错误历史。
- 清理数据在停止 VPN 之前失败时明确尚未删除数据；进入删除阶段后的失败不承诺数据完整保留。
  不增加全局错误弹窗，也不通过全局禁用交互处理失败。

### 目录组织

`lib/pages/` 和 `lib/service/` 按相同的业务归属组织：`connect`、`servers`、
`advanced`、`settings`；`launch` 负责启动与初始化，`shared` 保存跨页面复用的实现。
页面仍只依赖服务与 Core，服务不反向引用页面；目录位置不改变路由 URL 或导航栈。
连接、服务器和最终出口选择页各自持有独立的页面状态，不通过 Controller 继承复用。
节点展示数据由服务在数据库列表变化时解析；页面只共享展示与分组逻辑，单节点查询仍为一次性读取。

- 路由和响应式外壳：`lib/pages/main/`
- 连接：`connect/`；智能与自定义路由归 `connect/routing/`，Raw 编辑和运行配置也归连接。
- 服务器：`servers/`；订阅表单、导入和节点管理集中在该入口，不保留独立订阅根目录。
- 高级：`advanced/tunnel/` 放平台 VPN 配置；`advanced/xray/` 放路由数据、日志、运行配置、测速设置和数据更新。
- 设置：`settings/` 放根页、关于、外观、语言及 App 更新。
- 共享：`lib/pages/shared/` 放公共控件、页面状态和分享页；`lib/service/shared/` 放分享协议、测速执行、事件状态和通用运行支持。
- 主题：`lib/pages/theme/` 继续作为唯一公共主题入口；对应测试按相同归属组织在 `test/pages/` 和 `test/service/`。
- 运行与提交：[Xray 配置合同](xray-configuration.md)
